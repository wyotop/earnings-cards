Earnings Cards

A private tool for one creator. It is not available to the public.

Earnings Cards reads the owner's own YouTube Analytics and store sales once a day and turns them into a short earnings summary for the owner. Nobody else can sign in or use it.

Privacy policy

  • What it reads: read-only YouTube Analytics and channel data for the owner's own channels, and the owner's own store orders.
  • What it writes: one spreadsheet and one summary file in the owner's own Google Drive. It can't see any other Drive files.
  • Where data goes: it stays on the owner's computer and in the owner's Google Drive. It is never sold, shared or used for ads.
  • Access: sign-in keys are stored only in the owner's computer keychain. Access can be removed at any time at myaccount.google.com/permissions.

Use of data from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
